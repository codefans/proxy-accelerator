## 0. 初步数据（2026-10-10 08:55，开发机 Windows，WLAN 802.11n）

> 来源：开发机本身，不是宿舍笔记本；网卡是 72 Mbps 的 802.11n WiFi，带宽数字不代表有线。
> **如果开发机不在宿舍网络上，下面这节作废**，以笔记本跑 `scripts/probe-network.sh` 的结果为准。

| 项 | 结果 | 结论 |
|---|---|---|
| ISP | AS9299 PLDT，Makati City | 住宅 ISP，符合预期 |
| 出口 IPv4 | 112.211.115.164 | 公网地址存在，但见下一行 |
| NAT 层数 | 跳 1 `192.168.1.1`（宿舍路由）→ 跳 2 `100.83.0.1`（100.64/10，运营商 CGNAT）→ 跳 3 起公网 | **确认 CGNAT，没有公网 IPv4**。不能直连，必须中转 + WireGuard 反连 |
| IPv6 | 全局地址 `2001:4450:835a:9500::/64`（PLDT，RA 分配），出站可用：TCP 443 到 Cloudflare v6 通、ping6 Google 10/10 | **有公网 IPv6**，`PH-直连(IPv6)` 线路可做；入站是否被路由器防火墙挡住，要等有 VPS 后从外面测 |
| 丢包/延迟 | 1.1.1.1 30/30 收到，26 ms；8.8.8.8 30/30，6 ms | 本地到 anycast 无丢包 |
| 出站端口 | TCP 443 / 8443 / 2053 通；UDP 53 通 | 宿舍网络没封非标准端口 |

**对架构的影响**：维持中转方案不变；IPv6 直连线路从"可选"升为 M2 必做（国内移动网络 IPv6 普及，这条线路少一跳且不占中转流量）。
