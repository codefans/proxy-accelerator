# 使用说明（发给用户的版本）

你会收到一个**订阅地址**，形如 `https://sub.xxx.com/sub/一长串字母数字`。它就是你的账号，不要转发给别人。

## 电脑（Windows / macOS）：Clash Verge Rev

1. **安装**：打开 https://github.com/clash-verge-rev/clash-verge-rev/releases ，下载最新版。Windows 选 `x64-setup.exe`，macOS 按芯片选 `aarch64.dmg`（Apple 芯片）或 `x64.dmg`（Intel）。安装时 Windows 可能弹出"Windows 已保护你的电脑"，点"更多信息 → 仍要运行"。
2. **导入订阅**：打开 Clash Verge → 左侧 **订阅** → 顶部输入框粘贴订阅地址 → 点 **导入**。几秒后出现一张名为 `ph-dorm` 的卡片，点一下选中它（卡片上会显示已用流量和到期日）。
3. **开启**：左侧 **设置** → 打开 **系统代理** 开关。完成。浏览器打开 https://www.google.com 能看到就是通了。

日常只需要记住：**设置 → 系统代理** 开关控制开/关；订阅每 12 小时自动更新，不用管。

## 手机

- **Android**：装 [FlClash](https://github.com/chen08209/FlClash/releases)（选 `android-arm64-v8a.apk`）或 Clash Meta for Android。打开 → 配置 → 右下角 + → **URL** → 粘贴订阅地址 → 保存，回到首页点开关。
- **iPhone**：需要 App Store（非中国区）里的付费 App：Shadowrocket（约 $2.99）或 Stash。在 App 里"添加订阅"粘贴地址即可。

## 节点怎么选

导入后在 **代理** 页会看到几个分组，默认不用动：

| 分组 | 含义 |
|---|---|
| 🚀 节点选择 | 总开关，默认选"♻️ 自动(PH优先)" |
| ♻️ 自动(PH优先) | 优先走菲律宾宿舍出口，它断了自动切到香港/日本中转，恢复后自动切回 |
| 🤖 AI 服务 | ChatGPT / Claude / Gemini 固定走菲律宾住宅 IP，这样不会被当机房 IP 拦截 |
| PH-宿舍 hy2 / reality | 同一条线路的两种协议。hy2 快；如果 hy2 连不上（有的宽带限制 UDP），手动选 reality |
| HK-中转 hy2 / reality | 备用线路，不经宿舍 |

国内网站（淘宝、B 站、微信等）自动直连，不走代理，不影响速度。

## 常见问题

**连不上 / 一直转圈**
1. 先看 Clash Verge 左侧 **订阅** 页卡片是否过期或流量用完（卡片上有显示）。
2. **代理** 页 → 点右上角闪电图标测延迟。全部超时 → 换手机热点试一下，能连说明你的宽带在限制，把 🚀 节点选择 手动改成 `PH-宿舍 reality`。
3. 还不行发消息给我，我这边有监控会先知道。

**视频卡**：宿舍上行带宽有限，晚上 8 到 11 点同时在线的人多会慢。看 1080P 够，4K 不保证。

**某个国内 App 打不开或被判为海外登录**：**设置 → 系统代理** 临时关掉再开那个 App。

**ChatGPT 提示"不支持的地区"**：确认 🤖 AI 服务 分组选的是 PH-宿舍，而不是 HK-中转。

**订阅地址泄露了**：告诉我，我换一个新的给你，旧的立刻失效。

**隐私**：服务器只记录每个账号用了多少流量，不记录你访问了什么。
