# 中转 VPS 选型（2026-10）

> 价格来自第三方页面，下单前以官网为准。中转的职责只有两件：国内用户连得稳（CN→VPS 线路）、到宿舍的隧道通（VPS→PH，HK/JP 到菲律宾一般都没问题）。流量都从宿舍出，VPS 的 IP 是不是机房 IP 无所谓。

## 1. 免费 VPS：有，但不能当主力

| 方案 | 能拿到什么 | 对本项目的问题 |
|---|---|---|
| **Oracle Cloud Always Free** | ARM A1 2 OCPU / 12 GB（2026-06 从 4C/24G 砍半），每月 10 TB 出站免费；区域可选东京 / 大阪 / 首尔 / 新加坡 | ① 注册要过信用卡验证，拒绝率高，主区域注册后不能改（选东京）；② A1 经常 "out of host capacity" 开不出来；③ 7 天内 CPU、网络、内存 95 分位都低于 20% 会被当闲置回收，中转这种负载大概率中招，据说升级 PAYG（绑卡但不消费）可豁免，Oracle 原文没写明；④ 账号被判"滥用"直接封且不解释，代理用途有先例；⑤ 国内到 Oracle 东京晚高峰质量一般 |
| 云厂商赠金（GCP $300/90 天、Azure $200/30 天、AWS 新免费额度） | 短期能开机 | 出站流量按 GB 计费，到中国大陆方向尤其贵（GCP 约 $0.23/GB），1 TB 就吃掉 $100–230；赠金到期即停。只适合做几天的线路测试 |
| GitHub 学生包 | Azure for Students $100/年，不需要信用卡（18 岁以上，需学生身份验证）；DigitalOcean $200 额度一说已于 2026-07-31 结束，官方页面待核实 | 同上，Azure 出站计费；如果你有在读学生身份，Azure $100 可以当"免费测试机"用两三个月 |
| Cloudflare Workers 做入口 | 免费 | 不支持 UDP、不能跑 WireGuard 到宿舍、违反 CF 条款，与本架构不兼容，不考虑 |

**结论**：如果 Oracle 能注册成功，拿它当**备用中转/测试机**，白嫖 10 TB 流量；不要让它当唯一中转，因为回收和封号都不可控。订阅服务和用户数据放在付费机上。

## 2. 付费选型

| 阶段 | 推荐 | 价格（约） | 流量 | 为什么 |
|---|---|---|---|---|
| **M1–M2 验证期（1–2 个月）** | Vultr 东京/大阪，或 Linode 东京，或 DigitalOcean 新加坡，最小配置 | $5–6/月，按小时计费 | 1–2 TB/月 | 注册即开、支持 PayPal/卡；**被封 IP 时销毁重建换 IP 只要几分钱**，验证期最怕的就是换 IP 麻烦；国内线路是普通 163 线路，晚高峰可能丢包，但足够验证架构 |
| **M3 之后稳定运行** | 搬瓦工 CN2 GIA-E，机房选 **日本大阪软银 (JPOS_1)**，1 GB 方案 | $49.99/季（≈ $16.7/月），2 GB 方案 $89.99/季 | 500 GB/月（2 GB 方案 1 TB） | 三网晚高峰稳定、UDP 友好、可自助换机房；500 GB 对 5–10 个亲友够用，超了升 2 GB 方案 |
| 稳定运行的替代 | DMIT 东京 Pro（Premium，CN2 GIA）TINY | $21.90/月 | 核实 | 线路同级，月付灵活；东京 Lite/T1（$6.90/月）**没有大陆优化**，只有移动用户走 CMI 体验好，电信联通绕路，不要被低价吸引 |
| 香港 | 搬瓦工 HK CN2 GIA 2 GB | $89.99/月 | 500 GB | 到菲律宾最近（约 30 ms），但价格是日本的 5 倍，本项目延迟预算（PRD：80–120 ms）用日本够了，不值 |
| **不推荐** | 阿里云/腾讯云轻量 HK（¥34/月） | 便宜、线路极好 | 1 TB | 用户协议明确禁止代理，会被强制停机并关联实名账号，别碰 |
| **不推荐** | RackNerd / CloudCone 美西 $10–20/年 | 极便宜 | 大 | 国内晚高峰丢包高、到菲律宾绕一圈，延迟 200 ms+ |

**线路和你的测试用户运营商有关**：CN2 GIA 主要优化电信，软银对三网都友好，CMI 只对移动友好。M0 让测试用户说一下用的是电信 / 联通 / 移动，以及手机流量的运营商，决定前先让他对候选机房的测试 IP 跑一次晚高峰 tcping。搬瓦工和 DMIT 官网都有各机房的 looking glass 测试 IP，可直接喂给 `scripts/probe-network.sh` 的 `TARGETS`。

## 3. 建议的购买顺序

1. **现在**：买一台 Vultr 东京（或 Linode 东京）$6/月，按小时计费，用于 M1–M2。同时试着注册 Oracle 东京，成功了就多一台免费备机。
2. **M2 结束**：根据 M0/M1 的实测（晚高峰丢包、UDP 是否被 QoS、用户运营商分布）决定买搬瓦工软银还是 DMIT 东京 Pro。`relay/install.sh --restore` 迁移，用户订阅自动换地址。
3. **验证机不退**：Vultr 那台改成按需开机的备用中转（关机不计费，或销毁后要用再建），应对主中转被封。

## 4. 下单时看清的三件事

- **流量怎么计**：有的只计出站、有的计双向。中转出站 ≈ 用户下载量，双向计费时按 2 倍估。
- **是否允许代理用途**：Vultr / Linode / DO / 搬瓦工 / DMIT 对自用代理默认不管，但滥用投诉（SMTP、BT、攻击）会停机，这就是宿舍节点封 25 端口和 BT 端口的原因。
- **换 IP 的成本**：被封时能不能自助换（Vultr 重建几分钱、搬瓦工 $8.79 一次或免费换机房、Oracle 免费）。这比线路本身更重要，因为被封是迟早的事。
