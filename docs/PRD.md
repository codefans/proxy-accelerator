# 产品方案（PRD）· 宿舍家宽代理加速器

> 一句话：以菲律宾宿舍 WiFi 为出口、以 Clash Verge 订阅为交付形态，给中国大陆的亲友/小圈子提供一条可用、稳定、带住宅 IP 的跨境代理线路。

## 1.0 先说清楚的三件事（关键假设与风险）

| 项 | 结论 |
|---|---|
| **宿舍 WiFi 大概率没有公网 IPv4** | 菲律宾 PLDT / Globe / Converge 住宅宽带普遍 CGNAT，宿舍多为二级 NAT。因此**不能让用户直连宿舍**，必须有一台海外入口 VPS 做中转，宿舍节点主动"外连"到中转。这是整个架构的前提（见 ARCHITECTURE 2.1）。 |
| **目标用户规模按"亲友自用"设计** | 宿舍上行带宽是共享的、不稳定的（晚高峰 20–50 Mbps 很常见，菲律宾国际出口质量一般），实际可承载 5–10 人同时在线看 1080P。它不是一个能卖几百份的"机场"。 |
| **合规是硬边界** | 中国大陆：个人自用属灰色地带，**经营性提供（收费、公开售卖、国内平台推广）有被按"非法经营罪"追诉的先例**，收款记录是主要证据。菲律宾：法律不禁止 VPN，但宿舍/校园网 AUP 和 ISP 住宅条款通常禁止转售带宽或对外提供服务，违反会被断网。本方案定位：**不公开、不售卖、不在国内平台做任何推广；费用最多按成本 AA**。 |

如果上面第三条和你的真实意图不一致（想做收费服务），这份方案的技术部分仍然成立，但产品与运营部分需要你先做法务评估再定。

## 1.1 目标用户与场景

| 用户 | 核心场景 | 关键指标 |
|---|---|---|
| 国内亲友（主力） | Google / YouTube 1080P / Telegram / GitHub / 海外资讯 | 打开即连，视频不卡，一周不用管 |
| AI 工具用户 | ChatGPT / Claude / Gemini 网页与 App | **住宅 IP 通过风控**（机房 IP 常被 OpenAI/Anthropic 拦截或要求频繁验证），这是宿舍出口相对 VPS 出口的核心价值 |
| 流媒体用户 | Netflix / Disney+ 菲律宾区、Spotify | 住宅 IP 不被判定为代理 |
| 你自己 | 远程管理宿舍节点、看流量、加人/踢人 | 一条命令完成，无需进宿舍 |

**明确不覆盖**：国服/外服游戏低延迟（CN→HK→PH 两跳约 80–120 ms，且 UDP 质量不可控）、大流量下载/BT、企业用途。

## 1.2 核心价值主张

1. **零出口带宽成本 + 住宅 IP**：宿舍 WiFi 的上行是"免费"的，IP 是真实住宅 IP；相比纯 VPS 方案，省掉按流量计费的出口成本，并解决 AI/流媒体服务对机房 IP 的风控。
2. **标准订阅、零客户端开发**：交付物就是一个订阅 URL，Clash Verge（mihomo 内核）原生支持 Hysteria2 / VLESS+Reality；不自研客户端、不自研协议。
3. **中转与出口解耦，单点故障可兜底**：宿舍断网/停电时，用户自动切换到中转 VPS 自身出口；中转 IP 被封时换一台 VPS、订阅自动下发新地址，用户无感。
4. **可审计的最小系统**：用户表 + 节点表 + 流量统计，一个 SQLite，一个 CLI；不收集访问内容。

## 1.3 功能清单

### P0（MVP，必须有）
- **宿舍出口节点**：Linux 小主机常驻，WireGuard 主动外连中转，NAT 出口到宿舍 WiFi；断网自动重连、断电来电自启、远程 SSH（Tailscale 穿 NAT）
- **入口中转**：海外 VPS（HK/JP，对国内三网线路优化），sing-box 多用户入站：Hysteria2（UDP，端口跳跃）+ VLESS+Reality（TCP 443 兜底）
- **两条线路**同时下发：`PH-宿舍`（经宿舍出口，住宅 IP）和 `HK-中转直出`（VPS 自身出口，备用）；客户端 `fallback` 组自动切换
- **订阅服务**：每用户一个 token → `GET /sub/<token>` 返回 Clash YAML；带 `subscription-userinfo` 头（已用流量/配额/到期），Clash Verge 直接显示
- **用户管理 CLI**：加人 / 续期 / 禁用 / 改配额 / 查流量；变更一分钟内同步到 sing-box
- **流量统计**：按用户统计上下行，超配额或到期自动停用
- **分流规则**：国内域名/IP 直连，其余走代理；广告拦截可选
- **用户文档**：Clash Verge 导入订阅的三步图文

### P1（稳定性与运维）
- 节点健康监控与告警（Uptime Kuma 或 Telegram Bot 推送：宿舍掉线、WG 握手超时、VPS 失联、流量异常）
- 宿舍节点带宽自适应：按时段限速（晚高峰给宿舍同学留带宽）
- 第二台中转 VPS（不同 ASN）热备，订阅同时下发
- 节点侧 nftables 限速 / 连接数限制，防止单个用户打满上行
- 用户自助页（极简）：看流量、看到期、重置 token

### P2（仅预留接口，不实现）
- Web 管理面板、套餐/付费、邀请
- 迁移到 Xboard + V2bX 的路径（如果真要商业化，不自研面板）
- 多出口（多个宿舍/家宽节点）调度

### 明确不做
- 不自研客户端、不自研加密协议
- 不做国内中转（需要 ICP/备案，且合规风险最高）
- 不在国内任何平台推广、不接入微信/支付宝收款

## 1.4 线路与资源选型

| 组件 | 选项 | 建议 |
|---|---|---|
| **宿舍节点硬件** | A. 旧笔记本（自带电池 = 免费 UPS，菲律宾停电常见）；B. N100 迷你主机 + 小 UPS；C. 树莓派 4/5 | **A 优先**（零成本、抗停电）；无旧笔记本则 B。务必**网线接宿舍路由**，WiFi 只作兜底 |
| **宿舍节点系统** | Debian 12 最小安装 | 稳定、sing-box/wireguard 官方源齐全 |
| **入口中转 VPS** | HK CN2 GIA（DMIT / 搬瓦工 HK，$30–50/月）；JP 软银线路（$10–20/月）；阿里云轻量 HK（¥34/月，线路好但 ToS 禁止代理，随时可能被停） | 起步用 **JP 软银或 HK 普通线路**（$10–20/月）验证；体验不够再升 CN2 GIA。**从第一天就按"可随时换 VPS"设计** |
| **域名** | 任一海外注册商，托管到 Cloudflare | ~¥60/年。订阅域名走 Cloudflare 代理（橙云），与中转 IP 解耦 |
| **远程管理** | Tailscale（免费 3 用户） | 宿舍节点无公网也能 SSH |

**带宽预算**（需 Phase 0 实测后修正）：

| 场景 | 单用户峰值 | 宿舍上行 30 Mbps 可支撑 | 宿舍上行 80 Mbps 可支撑 |
|---|---|---|---|
| 网页 / IM / AI 对话 | ~1 Mbps | 20+ 人 | 50+ 人 |
| YouTube 1080P | 5–8 Mbps | 4 人 | 10 人 |
| YouTube 4K | 20+ Mbps | 1 人 | 3–4 人 |

## 1.5 与现成方案的对比

| 方案 | 适合 | 为什么不选 / 怎么用 |
|---|---|---|
| 直接买商业机场 | 省事 | 没有住宅 IP；本项目的核心价值正是宿舍出口 |
| Xboard + V2bX | 真商业化 | 面板 + 节点代理 + 支付一套全有，但重、攻击面大、面向售卖；P2 迁移路径预留 |
| 纯 VPS 节点（旁边 `freely-access-to-china-network` 的 `server/exit-node`） | 不需要住宅 IP | 其 sing-box 多用户脚本直接复用为本项目的中转入站 |
| **本方案：宿舍出口 + VPS 入口 + 轻量订阅服务** | 亲友自用 | 代码量最小（订阅服务约 300 行），其余是配置与脚本 |

## 1.6 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 宿舍 WiFi 没公网 IP | 无法直连 | 架构前提就是中转 + 反向隧道；Phase 0 同时探测 IPv6，有则多下发一条 IPv6 直连线路 |
| 宿舍断网 / 停电 / 路由器重启 | PH 线路中断 | 客户端 fallback 自动切 HK 直出；节点 watchdog 重连；笔记本电池撑过短时停电 |
| 宿舍/校园网检测到长期大上行流量 | 被限速或断网 | 节点侧限速到上行的 60–70%，夜间限更低；不做 BT；总量告警 |
| 中转 IP 被封 | 全线中断 | 订阅域名走 Cloudflare 与 IP 解耦；`relay/install.sh` 一键重建新 VPS；P1 双 VPS 热备 |
| UDP 被 QoS，Hysteria2 降速 | 体验差 | 同时下发 VLESS+Reality TCP；端口跳跃 |
| 晚高峰国际链路拥塞 | 卡 | 选三网优化线路；Hysteria2 的 BBR/Brutal 拥塞控制 |
| 法律 / AUP | 断网或追诉 | 1.0 第三条：不公开、不售卖、不收款、不推广；用户数控制在两位数以内 |
| 滥用（用户拿去干坏事，住宅 IP 背锅） | 宿舍 IP 被投诉 | 只给信得过的人；节点侧封禁 SMTP(25)、BT 常用端口；保留最少 7 天连接计数（不记内容）以便排查 |

## 1.7 成功标准（MVP 验收）

- 国内用户在 Clash Verge 粘贴订阅 → 连通 ≤ 2 分钟（含文档阅读）
- `PH-宿舍` 线路：`https://ip.sb` 显示菲律宾住宅 IP（ISP 名为 PLDT/Globe 等，非机房）；ChatGPT 网页不触发"不支持的地区"或频繁人机验证
- YouTube 1080P 连续播放 10 分钟无卡顿（晚高峰 21:00–23:00 测）
- 拔掉宿舍节点网线 → 客户端 30 秒内自动切到 `HK-中转直出`，插回后 2 分钟内 PH 线路恢复
- 宿舍节点断电重启后无人干预 3 分钟内恢复服务
- 新增一个用户到他能用：一条 CLI 命令 + 1 分钟
- 连续运行 7 天无需人工介入
